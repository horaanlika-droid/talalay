## Метод и его границы

1. **Силуэт.** Для наших кадров маска строится по градиенту (Sobel + дилатация + заливка) и отражение отсекается по строке контакта — работает надёжно.
   Для источников автоматическая сегментация **ненадёжна**: в `brand-source/cutouts/*.png` альфа-канал содержит только тонкий контур (доля пикселей с alpha > 40 — 3–5 %), а в прайс-листе стекло прозрачное и сливается с фоном. Поэтому числовые `IoU` по источникам не приводятся — они дают ложные значения.
2. **Пропорции.** Высота/ширина наших кадров меряется точно; по источникам — вычитывается глазом по парам (масштаб плашки одинаковый).
3. **Толщина стекла.** Оценивается визуально: толщина стенки, толщина дна/ножки, «массивность» стопы.

## Аудит «толщина стекла»

Требование заказчика: **дно тоньше**. Проверено по всем 10 кадрам:

* дно/стопа трактуется как тонкий полированный диск, нигде нет массивного блока;
* толщина стенки визуально одинаковая по сету, «толстых» зон нет;
* у петли «чаша → ножка» и в кнопе у `footed` сохранены локальные утолщения — это физика, в источнике они тоже есть.

Замечание: в файлах `martini`, `saucer`, `footed` (перегенерированы 31.10) ножка/кромка читается чуть плотнее, чем в alpha-кате — расхождение в пределах 1–2 px на 1000 px, на карточке не видно.
